# Reader Web

[한국어](#한국어) | [English](#english)

## 한국어

Reader Web은 Reader Server의 Vue 2 기반 웹 프론트엔드입니다.

### 지원 언어

- English
- 한국어
- 중국어

앱 환경설정에서 언어를 바꿀 수 있으며, 선택값은 브라우저에 저장됩니다.

### 기능

- 책장/검색/읽기 화면
- 읽기 기록과 설정 저장
- 읽기 테마 전환
- 야간 모드
- 글자 크기, 글꼴, 읽기 폭 조정
- 책 소스 관리와 디버그 화면
- 로컬 책 가져오기
- WebDAV/로컬 책 창고 연동

### 개발 명령어

```bash
npm install
npm run serve
npm run build
npm run lint
```

## English

Reader Web is the Vue 2 frontend for Reader Server.

### Supported Languages

- English
- Korean
- Chinese

The language can be changed in the app settings, and the selected value is stored in the browser.

### Features

- Bookshelf, search, and reader pages
- Local reading history and settings
- Reader theme switching
- Night mode
- Font size, font family, and reading width controls
- Book source management and debug page
- Local book import
- WebDAV/local book store integration

### Development Commands

```bash
npm install
npm run serve
npm run build
npm run lint
```
